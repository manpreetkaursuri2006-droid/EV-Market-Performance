# EV Market Performance & Insights
## Project report

### 1. Introduction
Electric vehicles (EVs) are an important part of the transition toward lower-emission transportation. This project uses Tableau to organize EV market data into an interactive dashboard for comparing manufacturers, observing sales trends, and exploring regional differences.

### 2. Objectives
- Compare annual EV sales across manufacturers.
- Track changes in sales over time.
- Compare market activity across regions.
- Explore market-share, price, and vehicle-range patterns.
- Present findings in a clear interactive Tableau dashboard.

### 3. Tools
- Tableau Public for data visualization and dashboard design.
- CSV data source for tabular market data.

### 4. Methodology
1. Import the CSV dataset into Tableau.
2. Check field types and missing values.
3. Build manufacturer, trend, regional, market-share, and price/range views.
4. Add dashboard filters and informative titles.
5. Validate visualizations against the source data.
6. Publish the completed workbook to Tableau Public.

### 5. Dashboard components
- Manufacturer sales comparison (bar chart).
- Annual sales trend (line chart).
- Regional sales comparison (bar chart).
- Market-share view (pie chart, when suitable).
- Vehicle price versus range (scatter plot, when fields are available).
